# 🖼️ 基於 AI 輔助之互動式影像處理與人臉分析工具

本專案為一個基於 Gradio 的互動式影像處理與分析系統，整合色彩空間轉換、動態直方圖分析、空間域卷積濾波、PSNR 計算以及基於 HOG 特徵的人臉偵測模組。

## 🌟 核心功能
1. **影像載入與解析**：支援 PNG, JPG, BMP，解析解析度、通道數與記憶體占用。
2. **多色彩空間與直方圖**：支援 Original, R/G/B 通道分離與 YUV 色彩空間轉換，動態渲染像素強度直方圖。
3. **自訂卷積核與 PSNR**：支援自訂 3x3 / 5x5 卷積矩陣與自動正規化，即時計算 PSNR（dB）。
4. **人臉偵測模組**：採用 HOG 特徵檢測器，標記 Bounding Box 並回傳總人數。

## 🚀 本地端執行方式
```bash
# 1. 安裝相依套件
pip install -r requirements.txt

# 2. 啟動應用程式
python app.py
```
